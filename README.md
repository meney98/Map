# Fonadhoo House Map – Wamco-style household labels

Upload all files in this folder to the root of your GitHub Pages repository.

Changes:
- household/place names use extra-small text
- nearby words are combined only when they are genuinely close, preventing unrelated house names from merging across blocks
- B-number reference labels are hidden
- search highlight is black/white, not red
- zoom, pan, search and clickable labels remain enabled
